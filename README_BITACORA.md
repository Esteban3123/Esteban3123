## Cómo completar

1. Abre `datos_bitacora.py` y llena todos los campos.
2. Ejecuta:

```bash
python3 generar_bitacora.py
```

3. Se actualiza el archivo `.docx`.
4. Firma (aprendiz, instructor y jefe) y súbelo al espacio del SENA.

## Campos que debes enviarme / completar

### Aprendiz
- Nombre completo
- Tipo y número de documento
- Teléfono
- Correo institucional y personal
- Dirección de residencia
- Número de grupo (ficha)
- Modalidad de formación
- Programa de formación
- Modalidad etapa productiva (presencial / virtual)

### Empresa
- Nombre, NIT, dirección
- Nombre, cargo, teléfono y correo del jefe inmediato / supervisor

### Instructor SENA
- Nombre y correo

### Alternativa (marcar una)
- Contrato de aprendizaje
- Monitoria
- Proyecto productivo
- Contrato de vínculo formativo
- Vínculo laboral

### Actividades (mínimo 3–5 del periodo)
Para cada una:
1. Descripción de lo que hiciste
2. Competencias del programa aplicadas
3. Fecha inicio / fin
4. Evidencia (documento, proceso, producto, entregable)
5. Observaciones / dificultades

### ARL
- ¿Afiliado? Sí/No
- Nivel de riesgo (I–V)
- ¿Corresponde al trabajo? Sí/No
- ¿Cuenta con EPP? Sí / No / NA
